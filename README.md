# 하루결 (Harukyul)

> 하루의 결을 따라가는 개인용 업무·컨디션 관리 도구

바탕화면에 스티커 메모처럼 상주하는 데스크톱 앱입니다. 하루를 시간 블록으로 나눠 할 일의 부하를 분산하고, 업무를 잘게 쪼개 안전하게 보관하고, 그날의 컨디션을 기록으로 남겨 패턴을 눈으로 확인합니다.

혼자 쓰려고 만든 도구라 **계정·서버·수집이 없고, 모든 데이터는 내 컴퓨터에만** 저장됩니다.

> 📸 스크린샷은 추후 추가 예정

---

## 왜 만들었나

업무를 자주 놓치고 일정을 까먹는 문제를 스스로 다루려고 만들었습니다. 핵심은 세 가지입니다.

- **부하 분산** — 모든 일을 한 번에 떠안지 않고 하루의 시간대로 나눠 배치합니다.
- **머리 비우기** — 떠오른 일을 일단 보관함에 던져두고, 할 수 있는 만큼만 꺼내 씁니다.
- **기록으로 보기** — 기억이 아니라 기록으로 컨디션의 흐름을 확인합니다.

---

## 핵심 기능

### 업무 관리
- **주요 업무 보관함** — 떠오른 일을 시간대 고민 없이 일단 던져두는 곳
- **시간 블록** — 아침 · 점심 · 저녁 · 밤, 여기에 선택형 **긴급 블럭**까지
- **블럭당 3개 제한** — 한 시간대에 너무 많이 몰지 않도록 과부하 방지
- **이중 배치** — 같은 업무를 필요하면 여러 블럭에 동시에
- **하위 업무 체크리스트** — 각 업무를 접히는 체크리스트로 잘게 쪼갬
- **작업 4상태** — 시작 전 → 진행 중 → 완료 → 종료(취소)
- **남은 업무 칸 + 자정 자동 이월** — 못 끝낸 일(시작 전·진행 중)은 날이 바뀌면 자동으로 다음 날로

### 컨디션 기록
- **하루 상태** — 단어 5단계(해냄 · 즐거움 · 그럭저럭 · 가라앉음 · 무너짐)와 **1~5 척도** 모드를 설정에서 전환. 두 모드는 서로 연동됩니다.
- **지난 흐름** — 최근 2주의 상태를 색 막대로 한눈에

### 통계 (최근 2주)
- 감정 추세선 · 작업 활동(상태별 개수 · 완료율) · 하위 업무 수 · `[대괄호]` 분류별 집계

### 데스크톱 편의
- 항상 위(always on top) · 트레이 토글 · 반투명 · 시작 시 자동 실행 · frameless 작은 창

### 데이터 안전
- 로컬 **JSON 파일** 저장(원자적 쓰기)
- **자동 일별 백업**(최근 14일치 롤링)
- **단일 인스턴스** — 한 기기에서 하나만 실행해 기록 충돌·유실 방지
- 파일 손상 시 원본 보존 후 **백업에서 자동 복구**
- 저장 폴더를 OneDrive 등에 두면 기기 간 백업
- JSON 내보내기 / 가져오기

## 설치 및 실행

요구 사항: **Windows**, **Node.js / npm**

```bash
npm install       # 최초 1회
npm start         # 개발 모드로 실행
npm run build     # 포터블 실행 파일 빌드 → dist\하루결-portable.exe
```

빌드된 `하루결-portable.exe`는 **설치 과정이 없는 단일 실행 파일**입니다. 바탕화면 등에 두고 바로 실행하세요.

> 빌드 중 심볼릭 링크 권한 오류가 나면 Windows **개발자 모드**를 켜거나 PowerShell을 관리자 권한으로 실행하세요.

## 데이터 & 프라이버시

- 계정도 서버도 없습니다. 데이터는 전부 내 컴퓨터에만 있습니다.
- 저장 위치는 앱의 **⚙ 설정 → 데이터 저장 폴더**에서 확인·변경할 수 있습니다.
- 백업은 그 폴더 아래 `harukyul-backups\`에 날짜별로 쌓입니다.
